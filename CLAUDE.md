# Jato · novosti o propisima

Ovaj repozitorij sadrži samo `propisi.json`, koji aplikacija Jato prikazuje korisnicima (OPG-ovima s peradi).

- Izmjene rade se isključivo prema `UPUTE-ZA-PROVJERU.md`.
- Prije pull requesta pokreni `node validate.cjs staro.json`, gdje je `staro.json` verzija s grane `main`.
- Nikad se ne gura izravno na `main` i ne spaja se vlastiti pull request: vlasnik pregledava svaku izmjenu.
